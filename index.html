☁️ 云同步（孩子的 iPad 和你的手机数据互通）

状态：未配置云同步

📖 配置方法（每台设备做一次：你的手机 + 孩子的 iPad）：
1️⃣ 电脑登录 github.com → 右上角头像 → Settings → 左侧最下方 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token；
2️⃣ Token name 随意 → Expiration 选 1 year → Repository access 选 Only select repositories 并勾选 daka 仓库 → Permissions → Repository permissions → Contents 选 Read and write → Generate token → 立刻复制（只显示一次）；
3️⃣ 第一台设备（比如你的手机）：把 Token 粘到上面，仓库名填 你的用户名/daka，文件名留空（自动生成一个随机名）→ 保存并启用；
4️⃣ 之后的每台设备（iPad、Mac…）：粘 Token 和仓库名，数据文件名必须抄第一台设备上显示的那个（形如 data-xxxxxxxx.json，一字不差）→ 保存并启用。
⚠️ 所有设备的数据文件名必须完全一致，留空会生成新文件，各存各的、互相看不到！
🔒 令牌只保存在每台设备本机，不会上传到任何地方；即使被人看到，也只能读写 daka 这一个仓库，动不了你 GitHub 里的其他东西。Token 到期（最长 1 年）后重新生成一次即可。
👀 只看不改的设备（比如 Mac 上的看板）：令牌留空、只填仓库名，即可进入只读模式——自动拉取最新数据，但本机的修改不会上传（防止误改）。
